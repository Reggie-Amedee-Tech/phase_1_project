## Part 1: Identify Resource & Create GitHub Repo (Due by 5/21)

First, you will identify a data collection resource that interests you and your team. We provide a list of possible APIs and websites to scrape from underneath the section titled "Data Collection Options", however, you are free to select a resource of your team's choosing. However, this resource cannot be an already formatted CSV file. You should choose a resource that currently exists in an unstructured or semi-structured format. 

Furthermore, you will be using the end-product of this project (the dataset itself) in your Phase 2 end-of-phase project to generate predictions. Therefore, you must identify which dependent variable you will be predicting, and which independent variables you will use to form these predictions. Essentially, you must answer the following questions:

- What does your dataset explore?
- What is your dependent variable in the data you are pulling from?
- Is this variable categorical or quantitative? 
- What are your independent variables?
- Are these variables quantitative or categorical? (you should have a good mix of both types, i.e. not all categorical)
- How many independent variables do you have? (you should have more than 5 independent variables)
- How large is your dataset? (it should be larger than 1000 rows, but the more the better the powerLinks to an external site.)
- These questions should be answered in your README.md file in an organized format. Use the template attached to create this README file.
